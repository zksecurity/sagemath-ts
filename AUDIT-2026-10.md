## October 1 — small-prime initialization and scalar backends (28.0.0)

Read PARI elliptic.c:773–810/2289–2316. Integer domains two and three must use
FF records; the prior adapter returned integer/Fp records, threw for singular
curves and left short ternary multiplication on the local Jacobian fallback.
The entry point now delegates to the existing native FF initialization and
scalar ports. The mutable short-record cache handles both model families and
unwraps degree-one coordinates at the short-point API boundary. The unused
local scalar fallback was removed.

The public ellinit result type is now an integer/FF/null union for a general
bigint domain, with precise domain-free and literal small-prime overloads.
Existing valid p>3 test/caller records are explicitly narrowed. Field accessors
preserve scalar types. ellisnonsingular previously compared a field-element
object to bigint zero, incorrectly accepting singular FF records; it now tests
the actual field value. Existing native singular-record cases now compare this
predicate as well as coefficients, discriminant, j, model and domain type.

Twelve new compact controls and fresh generators compare integer-domain
initialization, singular returns, binary/ternary scalar outputs, optimized Sage
caller state/coercion and mutable short-record cache reuse. Before the repair,
all 87 new small-prime initializer checks failed (4253424393/2030400033,
runs=40). The native oracles remain temporary executables, with no stored outputs.

Final validation: 3,033 existing/general/optimized model comparisons
(3072025758/runs=300), 1,869 odd comparisons (3611305920/runs=300), and 1,834 binary
comparisons (1607498517/runs=300). All 267 affected unit tests and 391 docs/storage
checks pass. All eight builds pass. All 568 complete normalized diagnostic blocks
match the frozen typecheck baseline; no baseline refresh. Versions are 28.0.0.

Remaining: finite-field order/cardinality/group backends, native input coercion
and API boundaries, torsion and remaining module inventory. Singular ellinit
outside p=2/3 retains its older exception behavior, explicitly tracked in
DEVIATIONS.md. Returning a native FF record does not establish the missing group
backends. Next dependency: bb_group.c gen_order and the three extension order
wrappers; cardinality additionally needs native Satoh/Kohel/Harley/Kedlaya/SEA
branches rather than an exhaustive substitute.
